# Front-end Development CA1

Rodrigo Moura | Student ID: 81200 | Group: BSC20926A

This repository contains the HTML exercises for the CA1 assessment. Open
`index.html` with an internet connection: the assessment uses TailwindCSS from
the CDN, and the two image exercises load Google Fonts.

| Page | Exercise |
| --- | --- |
| `index.html` | Home page, exercise links, developer image and favicons |
| `exercises/page-1.html` | HTML structure, typography and colour |
| `exercises/page-2.html` | HTML debugging, semantic structure and typography |
| `exercises/page-3.html` | Six sections, two lorem ipsum paragraphs per section, colour classes and custom colour properties |
| `exercises/page-4.html` | Images, relative links, internal anchors and Merriweather |
| `exercises/page-5.html` | Images, relative links, internal anchors, Oswald and Lato |
| `exercises/hero-text.html` | Text hero, colour gradient and entrance animations |
| `exercises/hero-image.html` | Background image, overlay and layered text |
| `exercises/hero-video.html` | Background video, poster image and layered text |

All submitted HTML files include `<!-- Rodrigo Moura 81200 -->` inside their
`<head>`. The additional existing exercises are retained.

The home page keeps the earlier simple single-column layout, with a centred
heading, an image, a short introduction and a list of exercise links.
TailwindCSS controls the font family, text size, alignment, line spacing,
colours, margins and padding. The personalised introduction and the coding
photograph are retained; the photograph was already supplied in the original
repository. The image keeps its natural proportions as the page gets narrower.

The video can be paused with a keyboard-accessible button. Reduced-motion
preferences disable the entrance animations and pause the background video.
