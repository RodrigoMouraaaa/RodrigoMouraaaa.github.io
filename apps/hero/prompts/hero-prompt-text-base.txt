CONTROLS

Place a compact, clearly labelled control panel above the hero, outside the generated content. Do not use a form element.

Include exactly four native checkbox controls. Each checkbox must have a clickable text label, visible keyboard focus and a clear checked state.

1. “Dark appearance”
   - Default: unchecked.
   - Unchecked: light appearance, using bg-slate-50, H1 text-slate-900 and H2 text-slate-700.
   - Checked: dark appearance, using bg-slate-900, H1 text-slate-50 and H2 text-slate-300.

2. “Centre text”
   - Default: unchecked.
   - Unchecked: left-align both headings.
   - Checked: centre-align both headings and centre their constrained content blocks.

3. “Minimum height”
   - Default: checked.
   - Checked: apply min-h-[480px] md:min-h-[85vh].
   - Unchecked: remove the minimum-height styling, allowing content and padding to determine the height.

4. “Show subheading”
   - Default: checked.
   - Checked: display the editable h2.
   - Unchecked: hide the h2 so it takes up no space and cannot receive keyboard focus.
   - Preserve any edited subheading text when switching it off and back on.
   - Include the h2 in the copied HTML only when this checkbox is checked. Otherwise, omit the element entirely.
   - Keep the h1 visible and editable at all times.

Arrange the controls in a compact row where space allows, wrapping neatly on smaller screens.

Read each checkbox’s checked property in JavaScript. Changes should update the hero immediately without resetting the edited text.

- hero-min-height
